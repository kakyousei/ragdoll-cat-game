# 🐾 布偶猫养成记 · Ragdoll Cat Game

一个可以在浏览器里玩的布偶猫养成小游戏：领养一只软乎乎的布偶猫，陪它吃饭、玩耍、洗澡、长大。

## 在线玩

打开 GitHub Pages 地址即可游玩（无需安装、无需注册）：

**https://kakyousei.github.io/ragdoll-cat-game/**

## 玩法

- 🤲 **抚摸 / 🪮 梳毛**：提升亲密度，小猫会冒爱心、打呼噜
- 🧶 **玩耍**：提升快乐，消耗精力
- 🍽️ **小食堂**：用金币买猫粮、罐头、小鱼干
- 🎁 **卖萌打工**：赚金币（先赚钱，再喂好吃的）
- 🛁 **洗澡**：恢复清洁度，洗得香喷喷
- 🌙 **睡觉**：恢复精力，睡着了就不要吵醒它
- ⭐ 陪伴会积累**成长值**，小猫会从幼猫期一路长到优雅期
- 📖 所有互动都会记进**养成日记**，进度自动保存在浏览器里

## 本地运行

直接用浏览器打开 `index.html` 即可，不依赖任何服务器或网络资源。

## 技术

单个 HTML 文件（原生 CSS + JavaScript），猫咪是纯 SVG 手绘的，
没有外部图片、没有构建步骤，方便任何人查看和改编。
