# 🐾 布偶猫养成记 · ラグドール育成記 · Ragdoll Cat Game

**▶ Play / 在线玩 / 遊ぶ: https://kakyousei.github.io/ragdoll-cat-game/**

## 中文

一个可以在浏览器里玩的布偶猫养成小游戏：领养一只软乎乎的布偶猫，陪它吃饭、玩耍、洗澡、长大。

### 玩法

- 🤲 **抚摸 / 🪮 梳毛**：提升亲密度，小猫会冒爱心、打呼噜
- 🧶 **玩耍**：提升快乐，消耗精力
- 🍽️ **小食堂**：用金币买猫粮、罐头、小鱼干
- 🎁 **卖萌打工**：赚金币（先赚钱，再喂好吃的）
- 🛁 **洗澡**：恢复清洁度，洗得香喷喷
- 🌙 **睡觉**：恢复精力，睡着了就不要吵醒它
- ⭐ 陪伴会积累**成长值**，小猫会从幼猫期一路长到优雅期
- 📖 所有互动都会记进**养成日记**，进度自动保存在浏览器里

### 说明

- 游戏里的猫咪是主人家真实的布偶猫照片（已内嵌在 `index.html` 里），会随着睡觉、玩耍等状态切换，下方缩略图也可以手动换照片。
- 界面支持中文 / 日本語 / English 三语言切换（页面上方按钮），选择会被记住。
- 本地运行：直接用浏览器打开 `index.html` 即可，不依赖任何服务器。
- 技术：单个 HTML 文件（原生 CSS + JavaScript），没有构建步骤，方便查看和改编。

## 日本語

ブラウザで遊べるラグドール育成ゲームです。ふわふわのラグドールを迎えて、ごはん・遊び・お風呂でお世話しながら成長を見守ります。

### 遊び方

- 🤲 **なでる / 🪮 ブラッシング**：親密度アップ。ハートが出てゴロゴロ言います
- 🧶 **遊ぶ**：幸せアップ、元気を消費します
- 🍽️ **ごはん屋さん**：コインでカリカリ・缶詰・煮干しを買えます
- 🎁 **萌えバイト**：コインを稼げます（まず稼いで、おいしいものを買おう）
- 🛁 **お風呂**：清潔度が回復して、いい匂いに
- 🌙 **寝る**：元気が回復します。寝ている間は起こさないでね
- ⭐ お世話で**成長値**がたまり、子猫期から優雅期まで育ちます
- 📖 お世話の記録は**育成日記**に残り、進み具合はブラウザに自動保存されます

### 補足

- ゲームの猫は、飼い主の家の本物のラグドールの写真です（`index.html` に埋め込み）。寝る・遊ぶなどの状態で写真が切り替わり、下のサムネイルでも手動で切り替えられます。
- 画面は中文 / 日本語 / English の3言語に切り替えられます（ページ上のボタン）。選んだ言語は記憶されます。
- ローカルで遊ぶには `index.html` をブラウザで開くだけでOKです。サーバーは不要です。

## English

A little ragdoll-cat raising game that runs in your browser. Adopt a soft ragdoll cat, feed it, play with it, bathe it, and watch it grow.

### How to play

- 🤲 **Pet / 🪮 Brush**: raises Love — hearts appear and the cat purrs
- 🧶 **Play**: raises Happiness, uses Energy
- 🍽️ **Snack Shop**: spend coins on kibble, canned food, and dried fish
- 🎁 **Charm Job**: earn coins (earn first, then buy treats)
- 🛁 **Bath**: restores Cleanliness, leaves it smelling nice
- 🌙 **Sleep**: restores Energy — don't wake it while it sleeps
- ⭐ Caring for it builds **Growth**; it grows from Kitten all the way to Elegant
- 📖 Every interaction is written into the **Care Diary**, and progress auto-saves in your browser

### Notes

- The cat in the game is the owner's real ragdoll cat, from photos embedded in `index.html`. The photo changes with its state (sleeping, playing, …), and the thumbnails below the photo let you switch manually.
- The interface switches between 中文 / 日本語 / English (buttons at the top of the page); your choice is remembered.
- To run locally, just open `index.html` in a browser — no server needed.
- Tech: a single HTML file (vanilla CSS + JavaScript), no build step, easy to read and remix.
